# Blinkit AI Sales Analyzer 🛒🤖

AI-powered retail analytics project combining Power BI, Python, SQL, Pandas, and Groq Llama API to transform Blinkit sales data into actionable business insights. Features interactive dashboards, multilingual AI chatbot support (10 languages), KPI analysis, smart recommendations, and dynamic sales insights for data-driven decision making.

## 🚀 Features

* Interactive Power BI Dashboard
* AI-powered Sales Assistant
* Multilingual Chatbot Support
* KPI & Sales Trend Analysis
* Smart Business Recommendations
* Dynamic Filtering & Visualization

## 🛠 Tech Stack

Power BI • Python • SQL • Pandas • Groq API • Llama Model • Prompt Engineering
